# OBJECT-ORIENTED PROGRAMMING



> **Grade:** Highest Honors / Matrícula de Honor (10.3 / 10)  
> **Course:** Object-Oriented Programming (OOP) — 2nd Year, B.Sc. in Computer Engineering    
> **Institution:** Universitat Pompeu Fabra (UPF), Barcelona  

---

This repository contains the complete codebase and laboratories for the **Object-Oriented Programming** course at UPF. 

The main objective of the course was to design and implement a complete **Supervised Learning Framework** (Linear Regression with Gradient Descent and Stochastic Gradient Descent) from scratch. The project evolved from initial Java OOP architecture, data transformations, and inheritance design patterns into a high-performance C++ implementation.

---

## Key Features & Technical Highlights

* **OOP Architecture & Design Patterns:** Complete implementation of fundamental OOP principles: encapsulation, class hierarchies, abstract classes, polymorphism, and method overriding.
* **Machine Learning Engine from Scratch:** Built custom mathematical abstractions, feature normalization/standardization, full-batch Gradient Descent, and Stochastic Gradient Descent (SGD).
* **Multi-Language Paradigm (Java & C++):** Developed initial iterations in Java  and refactored the pipeline to modern C++ using dynamic pointers and memory management.
* **Version Control & Quality:** Incremental development managed with GitHub, validated with comprehensive test suites ensuring zero errors across iterations.
